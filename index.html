Digital Art

Web development

Description
I developed Philippiece during my Senior High School at STI College Tagum as a web-based educational sliding puzzle game built using HTML5, CSS, and JavaScript. The application runs directly on web browsers without installation, ensuring cross-platform accessibility.

It uses a tile-based sliding puzzle algorithm where users rearrange segmented historical images within a grid system to form complete visuals representing key events and figures in Philippine history. The project integrates game-based learning principles with responsive web design, combining interactive gameplay mechanics with structured educational content to promote critical thinking and historical awareness.

Graphic Design

Java Project

Description
Me and my fellow groupmates developed PokeCatch, a stage-based Java desktop game where players choose different themed maps, catch Pokémon, avoid bombs, and unlock new areas as they progress. The game features an interactive map selection screen, animated stage transitions, background music, and sound effects that enhance the overall experience. Each stage increases in challenge, leading to a final level that triggers a special ending sequence. Through this project, I focused on creating smooth gameplay, clear progression, and an engaging user interface while applying strong object-oriented design principles.
